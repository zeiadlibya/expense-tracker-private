# Cashgo - تطبيق المصروفات الشخصي

تطبيق عربي شخصي لإدارة الدخل والمصروفات والمحافظ، مع تسجيل دخول عبر Supabase، وتحليلات وسجل عمليات، ودعم التثبيت كتطبيق على الهاتف.

## الملفات التي ترفعها إلى GitHub

- `index.html`
- `style.css`
- `app.js`
- `site.webmanifest`
- `sw.js`
- `icon-192.png`
- `icon-512.png`
- `apple-touch-icon.png`
- `README.md`

## التخزين

Supabase هو مصدر البيانات الوحيد للبيانات المالية:

- الدخل
- المصروفات
- أرصدة المحافظ
- التحويلات
- المصروفات المقسمة
- الإعدادات
- البنرات وإحصائياتها

يستخدم `localStorage` فقط لتفضيلات بسيطة مثل العملة، وبيانات وضع التجربة المؤقتة تحت مفاتيح واضحة مثل `cashgo_demo_data`. بيانات الحساب الحقيقي تبقى في Supabase فقط.

## النشر على GitHub Pages

1. ارفع الملفات إلى المستودع.
2. من إعدادات المستودع افتح `Pages`.
3. اختر النشر من فرع `main` ومن مجلد `/root`.
4. افتح رابط GitHub Pages بعد انتهاء النشر.

## ملاحظات الأمان

- لا تضع أي `service_role` key داخل الواجهة.
- استخدم فقط Supabase URL والمفتاح العام publishable key.
- اترك RLS مفعلاً في Supabase.
